## 1 插件功能简述

在文章的属性区、开头三行、末尾三行，按照你的设置，一键插入自动统计出来的文档信息、或者你的自定义内容；点一下更新，这些内容还会按照文章当前状态重新统计、自动变更。

这些信息包括：文字统计，图片统计，各种特殊块统计，编辑标记，作者名，自定义文字、图片、链接……现在的 3.0 版本，还多了个插入自动生成的“文章结构思维导图”功能。以上可插入内容都拥有丰富的自定义选项，可按你的喜好 DIY。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-03.png)

## 2 基础功能介绍

下边结合我自己的使用场景，大致描述下插件的功能，我的插入习惯如下：

| 行数    | 插入内容      | 插入方式                         |
| ----- | --------- | ---------------------------- |
| 第 1 行 | 头图        | 在“显示自定义”粘贴链接，自动保存到附件文件夹并插入正文 |
| 第 2 行 | 各类统计信息    | 在“追加内容设置”中，按顺序选择想插入的信息标签     |
| 第 3 行 | 文章结构图     | 自动生成，可在“文章结构图”中进行自定义样式设置     |
| 尾 3 行 | 编辑时间 + 作者 | 在“追加内容设置”中，按顺序选择想插入的信息标签     |

### 2.1 可插入内容

我绞尽脑汁地设计了十几种可插入内容：

| 分类       | 具体内容                       |
| -------- | -------------------------- |
| **文字统计** | 字数、字符数、阅读用时、页数             |
| **图片统计** | 图片总数、本地图、网络图               |
| **特殊块**  | 嵌入数、链接数、注释数、脚注数、代码数        |
| **编辑标记** | 创建时间、修改时间（可选精确到日期还是时分秒）、作者 |
| **固定图文** | 4 个链接/图片空位                 |
| **自由发挥** | 3 个自定义空位                   |
| **内容框架** | 文章结构图                      |

### 2.2 文本显示类

我习惯在第 2 行插入三项内容：字数、阅读时间估算、图片数统计，最后一行（尾 3 行）插入编辑时间和作者名。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-04.png)

我现在的工作流变为使用 AI skill 工具程式化排版，已经不再需要将其设置为特殊样式；但我仍保留了自定义插入内容格式的功能，你可以在“显示自定义”中自行设置加粗、斜体、文字颜色。注意，这里的设置并非整行起效，你可以决定每一个元素的样式，一行之内收获万紫千红。这个样式是通过代码生成的（如下方代码段），可以稳定地导出到 pdf、html，但如果你想导出 word，得提前按照 [`optional/word-export/`](../optional/word-export/README.md) 提供的教程做几项一劳永逸的操作；但话说回来，如果没设置特殊格式，不需要额外操作就能正常导出 word。

```
<div style="text-align:justify;padding-left:2em;" data-aii="marker"><strong>全文共 4491 字</strong>｜<span style="color:#a23939 !important;">阅读用时约 15 分钟</span>｜<em>图片共 7 张</em></div>
```

除了格式，插件还支持自定义插入的文字内容——比如你可以不羁地将字数统计改为“这篇文章我辛辛苦苦地码了 9527 个字，我容易么我”——前后双文本框，容纳你的双份不羁。甚至你还可以把最后边的“字”变成“0 字”，统计出十倍的满足感。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-05.png)

如果你对于格式的要求更为特殊，比如想保留第一行插入的那串内容，第二行插入“代码数、链接数”这类统计，那你可以去首页加一行——最多支持前 3+ 后 3 共 6 行。如果你费劲巴拉设置完成发现行数设置错了，那也没关系。看到“排序模式”了么，勾选之后可以调换每行的顺序。另外，这个页面还有两处容易忽略的格式设置选项：一是对齐方式，二是缩进量——我一般会保持“两端对齐”加 2 格缩进，更契合中文阅读习惯。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-06.png)

### 2.3 图片显示类

这个功能，是将路径或者链接添加到文章的某个固定位置。如果你同时勾选了后边的“图片”选框，这个功能就变为将路径指向的图片复制到你设置的附件文件夹中，然后插入到目标位置。你的个人二维码、logo、头图……都可以用这种方法自动插入。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-07.png)

以上是第一次插入图片的流程，如果你重复执行，可能会遇到重复插入的问题。举个例子：你已经完成了一套信息插入，这套信息的第三行恰巧是一张图片。由于图片无法像文本一样在外边套“识别标记”，重新执行后，插件无法识别现在的第三张图是你手动添加的还是上一轮插件插入、本轮需要刷新替换的，为了保险起见，插件只能将图片重新插入一遍。

为避免这种尴尬，我引入了一个图片比对步骤：这个步骤会计算前后 6 行（其实是正常显示的 3 行，obsidian 中两个换行符才代表一个真正的换行）中所有图片的 MD5，如果和你想要插入的一致，则代表这张图片是需要删除后重新插入的；如果不一致，则证明这张图片是你之前手动插入的，会予以保留。因此如果你中途换过插入图片、导致无法使用 md5 查重，需要手动删除下。否则，再次执行插件，会将插入的内容自动放入最前、或最后的位置，相应地，无法检测到相同 md5 的图片会被挤到插入内容以外——放心，仍然不会删除。

提示下：一张图片正常占一行，如果你不小心在一行中设置了多个图片、或者其他文字类内容，那一定会显示不全。我做了个警告功能，你也可以选择关闭。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-08.png)

### 2.4 属性区

我之前写东西根本不用属性区（frontmatter），后来想用 base 数据库做点信息统计之后才想起来用。插件统计出来的信息可以同步写到属性区，数据库插件可以直接读取相应字段下的数据。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-09.png)

蓝色下拉框中的选项，是针对属性区的操作设置：不操作是啥都不干、尊重现状，写入是建立字段并写入数据，删除是删除字段和数据，清空是保留字段但清空数据。图片和链接这种不需要操作属性区的，你不需要选择，选了也没用。由于本插件主要目标是在文档插入可见信息，属性区的编辑不是重点，对这方面要求高的话，建议找专用插件做精细操作。

### 2.5 统计规则

字数怎么算、标点算不算、代码和注释剔不剔除、表情算不算词——这些都有开关，去“统计规则”页自己勾。如果还是觉得我想得不够周到，把代码丢给 AI 改——难改的逻辑和基础功能我都做好了，AI 改个统计规则还不手拿把掐的。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-10.png)

插件插入的内容会在统计前自动剔除：点更新时，插件会先把上一轮插入的信息全部删掉、再对剩下的正文重新统计，保证统计范围限定在你自己写的内容。图片是个例外，你可以选择是否计入由插件插入的图片。

### 2.6 其他设置

**语言切换**：界面与预置文案兼容中英双语，发英文平台的时候切过去就行。

**四套预设**：考虑到不同场景下的差异化需求，我给你留下四套预设空间。预设之间完全独立，可以一键切换插入内容——比如公众号、平台投稿、个人知识库各自来他一套。

**刷新方式**：至于自动刷新，维持 2.0 的结论：不做。原因当时说过，很难做到无感，频繁重插也增加负担。快捷键、左侧 ribbon 按钮、命令面板三个入口随你用。

## 3 文章结构图

开篇那个文章结构思维导图各位都看到了吧，就是由插件自动画好、一键插进来的。上一版想实现这个效果，我只能通过 Mindmap NextGen 插件生成，然后手动截图贴进来，样式还没太多自定义空间；文章结构更新之后又要重新生成、截图、粘贴。现在有了 3.0 版插件之后，工作流程变成了——你去设置里把“文章结构图”这个新标签位放到合适的位置，调好样式，然后点一下插入，整篇文章的结构图瞬间就出现或更新在那里了。生成的是一张 SVG 图片，存在你设置的附件文件夹里，可以稳定地导出、传播。

### 3.1 三种布局

结构图支持三种排布方式：横、纵、放射。**横向**——标题从左往右一级级展开，章节多、层级深的长文用它最稳，大致是“梳状效果”；**纵向**——各级标题瀑布一样从上往下排，文章不太长的时候更省空间，整体是“生根效果”；**放射状**——文章标题居中，各章节朝四面八方伸出去，呈现匍匐蔓延的“龟状效果”。

### 3.2 悉听尊“变”

样式设置逻辑是“全局样式”+“层级自定义”。全局与自定义样式的设置是联动的，全局一变，下面所有层级一起变。因此，我建议先在“全局样式”中设置好整体的样式，然后去“自定义样式”中对不同层级进行精细控制。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-11.png)

我设计了多种全局变色方案，单色、深浅、同色系、互补、彩虹……会根据你选定的基础颜色自动变色。无论你想按照层级变色、每一条线都变色、变色效果强一点还是弱一点（0-10 级）、变色效果是正向还是反向……悉听尊“变”。

### 3.3 连接样式

本级连向下一级的线——线型（弧形、直角、直线）、粗细、弧度、配色（变色），连接点圆圈要不要显示、空心还是实心、多大，都可以自定义。

### 3.4 节点框

这里是设置每个标题用何种方式限定或呈现的。比如“胶囊”就是用胶囊形的外框把内容框住，也就是我这篇开头的样式，其他样式还包括下划线、矩形、圆角矩形、无底纹。其底色，外框色，底色与外框怎么变色、变色效果强弱，外框粗细，要不要连接点，文字对齐与位置（连线上方、贴线、下方）……都能设置。同级之间的宽度，还支持“等宽”（整列对齐）或者“按字数”（框随文字走）设置。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183455-12.png)

这里需要特别介绍的是“避让次级”。这个选项的功能是，本级标题分布，是否需要避让下一级标题。如果勾选“避让”，则本级标题后边不会存在其他本级标题引出的子标题，级别之间的派生关系明晰（下方左图）；如果不勾选，本级标题按照设置的间距规则排列，整体较为紧凑（下方右图，注意看标题 1 和 2 的位置）。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183456-13.png)

是否自动添加序号也是在这里设置。如果你没有对文内标题自动编号，但是需要在结构图中引入编号，勾选后，会帮你按照 “1.2.3” 的样式自动附加编号。

### 3.5 其他设置

容易理解的我就不介绍了，再介绍几个容易忽略的选项：

**底色**：单色、暖橙渐变、紫蓝渐变、蓝灰渐变、浅灰渐变，也允许你做自定义渐变。

**行数控制**：你可以按照字数限定每行最多多少字，或者按照行数设置内容显示成多少行。我的设置是全局不限制，仅将标题拆为 2 行显示。

![](https://img.gongbentang.qzz.io/2026/10/05/1005-183456-14.png)

### 3.6 放射状方案

放射状方案里设计了一套角度系统：起始角度决定第一个章节朝哪儿，偏移角决定相邻章节隔多开。你设置的数值只是一个基础参考数值，放不下的时候，插件会帮你把角度撑开确保显示完全，先调角度、最后才放大半径，实在摆不下就往远伸。插件还会以 (90°×A + 45°) 度为边界，判断每层该横向还是纵向发展。

但放射状方案有时候不是很稳定，且设置余地不多。结构均衡的文章可以绘制得很好，结构不适合的文章画出来奇奇怪怪。比如以下是同一篇文章自动生成的放射状方案，唯一差异仅在于我是否将第四章一分为二。
